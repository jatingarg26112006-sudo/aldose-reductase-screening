# aldose-reductase-screening
Docking validation, virtual screening and molecular dynamics of natural compounds against human aldose reductase (AKR1B1)
## Structure
PDB ID: 1US0 — human aldose reductase (AKR1B1) in complex with the
NADP(H) cofactor (PDB code NDP) and the inhibitor IDD594 (PDB code LDT).
X-ray diffraction, 0.66 Å resolution, no mutations, monomer.
Chosen because of its very high resolution, low validation
outliers (no Ramachandran outliers), and a well-defined inhibitor
pocket, which makes it suitable for docking validation.
